# 开发进展 · Gastronomique 私人食物博物馆

> 最后更新：2026-10-05　·　当前版本：`main`（见 `git log`）

## 项目定位

收集世界美食、食材、饮品、餐馆与奇闻轶事的**私人百科**。不做商业推荐，强调个人品味与知识关联：随着记录增多，数据自然形成一张「美食知识网络」。自托管在家用树莓派 5，可通过一次性邀请链接分享给朋友（只读）。

## 功能清单

**浏览**
- 展厅：每日展品（封面图/视频）、统计、分区、最近入藏
- 图鉴：搜索、按类别/标签筛选、排序；「⚖ 选择对比」模式
- 我的 Atlas：已品尝 / 想尝 / 品尝日志（含价格）
- 奇闻、知识网络（自研力导向图）、美食地图、对比品鉴、品味档案、AI 探索
- 全局搜索 `Ctrl+K`，快捷新建 `N`

**藏品（10 类）**：食材、菜品、菜系、饮品、餐馆、生产者、地区、文化、事件、故事
- 字段：名称/原名/地区/简介/正文（支持 `[[名称]]` 链接与 `![[m:媒体ID]]` 内嵌）/轶事/来源/标签
- 风味 8 维雷达、健康印象、坐标、关系（带标签的有向边）、媒体、品尝日志

**录入（手机优先）**：分区折叠；类别/风味/营养均为点选；配料与标签为标签式输入；拍照/录像/相册；位置可搜索地名、粘贴地图链接、定位、点地图；新建草稿自动保存；点遮罩不关闭，有改动时确认放弃

**分享**：每页右上角「⇪」——分享图（PNG）+ 可编辑文案 + 素材包 ZIP（文案、Markdown、分享图、原图）

**权限**：馆长（admin）可编辑与使用 AI；访客通过一次性邀请链接进入，只读；未登录无法访问任何数据与媒体

## 技术架构

```
浏览器（原生 HTML/CSS/JS，无构建步骤；Leaflet 走 cdnjs）
   │  /api/*  /media/*
Fastify（Node 22）── 会话 Cookie 鉴权 ── sharp / ffmpeg 缩略图
   │                                    └─ Claude / DeepSeek（服务器代理）
PostgreSQL 16（文字、关系、日志、设置）＋ 磁盘 data/media（原文件与 thumbs/）
```

- 数据库迁移：`server/migrations/00N_*.sql`，启动时按序自动执行（记录在 `schema_migrations`）
- 前端单页路由：`#/`, `#/discover`, `#/atlas`, `#/stories`, `#/graph`, `#/map`, `#/compare`, `#/taste`, `#/ai`, `#/item/:id`
- 代码规模：约 3,000 行（app.js 1.1k、share.js 0.5k、后端 0.6k）

## 数据现状（开发机）

75 件藏品：食材 35、菜品 11、地区 7、生产者 7、餐馆 6、文化 3、菜系 2、饮品 2、故事 1、事件 1；19 件有坐标；约 110 条知识连接。主要来自示例数据、两份研究笔记导入，以及用户手动录入。

## 已知限制

- 地图底图、Leaflet、Google Fonts、地名搜索都依赖外网
- 「📍 当前位置」需 HTTPS（Tailscale HTTPS 或 localhost）
- 部分坐标为大致位置（已在「位置说明」中注明）
- AI 功能尚未用真实密钥完整跑通
- 无离线模式（PWA 仅有清单，没有 Service Worker）
- 单馆长设计；多人协作编辑未支持
